# 🛡️ QuantumVPN

> Современный высокоскоростной кроссплатформенный VPN-клиент на **Flutter** для **Linux Desktop** и **Android / Mobile**, использующий глобальную сеть бесплатных серверов OpenVPN (VPN Gate, Университет Цукуба, Япония).

---

## ✨ Возможности

* 🌍 **Глобальная база бесплатных серверов**: Десятки и сотни активных серверов в Японии, США, Германии, Корее, Великобритании и других странах.
* ⚡ **Индикаторы скорости и пинга**:
  - Реальная пропускная способность каждого сервера (в Мбит/с и Гбит/с).
  - Задержка (пинг в миллисекундах) с цветовой градацией качества.
  - Число активных сессий и рейтинг надежности.
* 🚀 **Быстрое подключение в 1 клик**: Автоматический выбор сервера с наивысшей скоростью.
* 🐧 **Поддержка Linux Desktop**: Нативное управление OpenVPN процессами и сетевым интерфейсом `tun`.
* 📱 **Поддержка Android / Mobile**: Генерация и экспорт файлов `.ovpn` для быстрого импорта.
* 📊 **Мониторинг трафика в реальном времени**: Живой счетчик скорости приема/передачи (Мбит/с) и таймер текущей сессии.
* 🛡️ **Безопасность**:
  - Аварийный выключатель (**Kill Switch**) для защиты от утечки реального IP.
  - Защита от утечек DNS (**DNS Leak Protection**) с выбором Cloudflare (1.1.1.1), Google (8.8.8.8), Quad9 или AdGuard.

---

## 🛠️ Стек технологий

* **Фреймворк**: [Flutter](https://flutter.dev) (Material 3 + Cyberpunk Dark Glassmorphism)
* **Архитектура**: StateNotifier & [Riverpod 2](https://riverpod.dev)
* **Сетевой клиент**: Dio
* **Шрифты и иконки**: JetBrains Mono, Inter, Lucide Icons
* **VPN Движок**: OpenVPN (AES-128/256-CBC, LZO compression, TUN/TAP)

## 📦 Сборка и запуск

### Запуск на Linux:
```bash
flutter run -d linux
```

### Запуск на Android:
```bash
flutter run -d android
```

### Сборка релизных пакетов:
```bash
# Linux Desktop:
flutter build linux --release

# Android APK:
flutter build apk --release --split-per-abi
```
